# Security Policy

## Supported Versions

This project is actively maintained on the `main` branch. Security fixes are applied there.

| Version | Supported |
| ------- | --------- |
| main    | ✅ |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not open a public issue**. Instead, report it privately by emailing:

📧 **fleuryniyokwizera2021@gmail.com**

Please include as much detail as possible:
- A description of the vulnerability and its potential impact
- Steps to reproduce it
- Any relevant logs, screenshots, or proof-of-concept code

You can expect an initial response within **72 hours**. Once the issue is confirmed, I will work on a fix and coordinate disclosure with you before any public release.

Thank you for helping keep this project and its users safe.
